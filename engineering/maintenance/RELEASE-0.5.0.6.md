# TurboDL 0.5.0.6

版本：`0.5.0.6`（相对 `0.5.0.5`）

本版修复插件路由下载时的任务遥测缺失，不改变公共 API、断点格式或插件 ABI。

## 修正内容

- 工厂创建的内置 HTTP 后端通过插件路由接替下载时，客户端会把当前任务的活动连接数、已接收字节、请求数和 HTTP 状态传给同一个任务。
- 修复应用内实际仍在使用内置 HTTP 下载、但任务详情一直显示 0 连接的问题。
- 路由后端使用客户端统一的全局连接预算，避免多任务下载绕过总连接上限。
- 任务结束后释放任务级预算绑定，避免长期运行累积状态。

## 验证

- 新增真实 HTTP 路由测试，覆盖请求/字节/活动连接峰值、全局单连接预算和 HTTP 403 状态保留。
- `RoutedHttpTelemetryTest` 3 项通过，0 失败。

## 兼容性

- Maven 坐标、`TurboClient` 提交接口、下载请求、事件类型和插件接口不变。
- 旧任务、断点文件和现有客户端无需迁移。
