# TurboDL 0.5.0.9

本版更新 Android 与 Windows x64 的 C++20 原生核心及 Kotlin/JVM SDK，修复无强 ETag 单源并发、停滞分片回收与续传速率基线三类问题。

- **单源无强 ETag 的会话内分段并发**：单一来源且开启多连接（或指定表示 ID）的 HTTP 206 任务，允许在同一次会话内并发分段传输；跨会话续传仍保持严格的来源校验策略。
- **停滞分片主动回收与限速协同**：新增按请求最近收包时间判定停滞分片的回收机制，当其余分片仍在活跃传输或全部分片长期无进展时主动回收并重派；启用全局限速时自动避免误杀受控请求，避免任务在尾段卡死。
- **SDK 续传测速基线修复**：`TurboClient.SpeedRecorder` 改用单调时钟 `System.nanoTime()` 并以首次上报字节数作为基线，修复断点续传恢复瞬间把已下载字节计入瞬时速率导致的测速虚高。
- **多端产物同步**：发布四种 Android ABI（16 KiB ELF 对齐）原生库、Windows x64 原生 DLL/CLI 与 JVM 兼容 SDK。Kotlin 公开接口、JNI 签名与断点格式保持向后兼容。
