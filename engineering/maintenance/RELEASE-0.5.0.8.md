# TurboDL 0.5.0.8

本版更新 Android 和 Windows x64 的 C++20 原生核心，修复高并发 HTTP 下载和双栈网络下的两类故障。

- 连接并发较高时，按配置的并发数分配每个请求的写盘缓冲。多个任务继续共用总缓冲预算，小预算仍会限制并行数。
- 网络断流后，退避时间只约束失败分片。无关分片继续传输和补位，HTTP 429/503 仍遵守来源冷却。
- 一个候选 IP 被网络策略拒绝后，libcurl 可以继续尝试其他可用地址。IPv6 候选被拦截时，正常的 IPv4 响应可以完成下载。
- 发布四种 Android ABI 的原生库、Windows x64 原生 CLI 和 JVM 兼容 SDK。Kotlin 公开接口、JNI 签名与断点格式保持兼容。

同一个 80 MiB 本地下载样本和 32 MiB 缓冲预算下，峰值活动请求从 32 路升到 64 路，输出 SHA-256 一致。98 项原生集成测试及 2 项组件测试通过，覆盖双栈地址、HTTP/2、HTTP/3、断流恢复和跨协议回归。实际网盘稳态速度仍需真机网络复测。
