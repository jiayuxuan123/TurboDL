# TurboDL 0.5.0.4 验证摘要

本版是探测稳定性与限流处理修复，不包含以吞吐量提升为目标的调度或写盘算法重写，因此不把单次测速包装成性能提升。

## 受控验证

- 真实 HTTP 429 和 503 响应：确认第二次请求在 `Retry-After` 到期后才发出，用户代理保持不变。
- 长限流：服务端返回300秒等待时，只发出1次探测，任务保留断点并以限流原因结束自动重试。
- 阻塞探测取消：暂停等待中的探测后，全局唯一连接名额可立即被下一任务使用，文件 SHA-256 正确。
- 弱校验器取消：取消指纹请求会在800毫秒超时内结束，不继续占用 HTTP 调度器。
- 相邻回归：连接复用、探测快速失败、探测元数据、续传指纹、源冷却和断点保留一起通过。

## 结论边界

- 本轮没有新增公网大流量测试；修复点由本地真实 HTTP 服务直接复现和验证。
- 不声明本轮提高所有网盘或所有网络的下载速度。
- 发布判断基于正确性、取消及时性、断点保留和相邻场景不退化，而不是单一吞吐数字。
