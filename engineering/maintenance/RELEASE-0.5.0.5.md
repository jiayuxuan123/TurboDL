# TurboDL 0.5.0.5

版本：`0.5.0.5`（相对 `0.5.0.4`）

本版修复下载失败时 HTTP 状态和阶段丢失的问题，不改变任务策略、断点格式或插件 ABI。

## 修正内容

- 分片请求开始后立即进入传输阶段。这样即使服务器在返回第一个字节前就拒绝请求，失败也不会再被误标为“探测”。
- 分片和整文件请求会记录最近一次真实 HTTP 错误码。最终错误会写成 `HTTP 429` 或 `HTTP 503`，不再只用“429/503”合并类别。
- 授权/时效失败会保留真实 `401`、`403` 或 `410`，方便区分链接过期与服务器限流。
- 任务释放时同步清理 HTTP 状态缓存，避免长跑进程中的任务级状态无界增长。
- 应用侧即使没有完整的请求耗时指标，也会保留可用的 HTTP 状态和失败阶段，不再把整条诊断丢弃。

## 验证

- 新增真实 HTTP 测试：探测成功后，分片持续返回 503；断言错误文本包含 `HTTP 503`，最终阶段为 `TRANSFERRING`，任务详情保留状态 `503`。
- 相关探测限流、长冷却、取消和连接预算测试继续通过。
- 发布门禁：117个测试套件、635项测试、0失败、0跳过。

## 兼容性

- Maven 坐标、下载请求、任务状态、断点文件和插件接口不变。
- 旧任务无需重新创建；旧版本已经上传的历史事件不会被改写，只有新任务会携带更精确的状态。
