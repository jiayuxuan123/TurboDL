# TurboDL 0.5.0.3 源恢复受控 A/B 证据

## 结论范围

本轮采用 9 组配对的最终数据。测试模型是双任务、128 KiB，来源并行容量为 2，
遵守 `Retry-After: 1s`，使用本地普通 HTTP 受控服务。该结果不是公网实测，
不能外推为公网环境或夸克等公共来源的普遍提速。

在本受控模型中：

- baseline 中位耗时为 `2383.386 ms`，candidate 为 `1453.049 ms`。
- 逐组耗时比值（baseline / candidate）的中位数为 `1.6401115039659337x`，
  JSON 记录的 95% 配对区间为 `[1.5947558405347428, 1.676037396371927]`。
- 9/9 组的 candidate 耗时均低于 baseline；逐组比值范围为
  `1.089153129x` 至 `2.636505238x`。
- 两侧 CV 分别为 baseline `23.135954381190887%`、
  candidate `1.3786516636976422%`。baseline 在扩展至 9 组后仍高于 15%，
  因而仍存在明显噪声和异质性边界；上述结果只能作为本地受控 A/B 证据，
  不能包装为稳定、普遍的性能结论。

## 可引用边界

- 可引用：上述本地受控模型、9 组配对数据、中位数、95% 配对区间、两侧 CV、
  逐组摘要检查及两个最终二进制的 SHA-256。
- 不可引用：公网下载、夸克或其他公共来源的普遍提速，生产环境固定收益，
  或其他硬件、网络条件下的性能承诺。
