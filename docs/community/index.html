Issues

A bug report is worth ten opinions. Useful reports include: the TurboDL version (v0.2.4.0), the JDK, the target URL or a minimal reproduction, and what you expected instead.

Open an issue↗

Before you open a pull request

These are the same steps the maintainer runs. Nothing secret, nothing extra.

the checklist

./gradlew test258 cases, 0 skipped, 0 failed
dependency directionruntime → core
plugin manifestturbodl-plugin.schema.json
docsone file in the repository per page

The suite covers byte-level correctness, resume and the plugin lifecycle; a change that breaks it is a change that is not ready.

Discussions

GitHub Discussions is not enabled on this repository, so this site does not pretend otherwise — questions go to Issues too.

What a useful report contains

Four fields, and a report missing any of them usually turns into three round trips of questions.

the template

versionv0.2.4.0
JDKoutput of java -version
targetthe URL, or a minimal reproduction
expected / actualwhat you expected instead

Nothing else is required, and nothing is collected automatically.

Contributing

Bug fixes, new plugin backends, and documentation corrections are all welcome. Please keep the dependency direction (runtime → core) and run ./gradlew test before opening a pull request — the suite covers byte-level correctness, resume, and the plugin lifecycle.
