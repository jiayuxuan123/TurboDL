Community

There is no chat server and no QQ group. Everything happens in the repository, where it is searchable and permanent.

Issues

A bug report is worth ten opinions. Useful reports include: the TurboDL version (v0.2.0.8), the JDK, the target URL or a minimal reproduction, and what you expected instead.

Open an issue

Discussions

GitHub Discussions is not enabled on this repository, so this site does not pretend otherwise — questions go to Issues too.

Contributing

Bug fixes, new plugin backends, and documentation corrections are all welcome. Please keep the dependency direction (runtime → core) and run ./gradlew test before opening a pull request — the suite covers byte-level correctness, resume, and the plugin lifecycle.

License
