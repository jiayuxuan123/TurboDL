Platform Link Parser

把分享链接变成可下载请求：微博（最高可用清晰度 MP4 + 图集）、小红书（无水印视频 + 原图）、Pixiv（每页 `urls.original`）。注册一个 `LinkParser` 与每个平台一条 `ProtocolClaim` — 引擎对这三个站点一无所知。

明确拒绝的情况

  • 登录 — 需要会话的平台返回 null，由宿主自己的账号处理接手
  • Pixiv 动图（ugoira）：zip + 帧时长表需要图像处理
  • Pixiv 小说
  • 需要签名的接口（抖音 / 快手 / B站）：各自的签名算法仍留在宿主侧
它的结果类型不含任何路径：`DownloadRequest` 需要 `destination: File`，而解析发生在宿主决定目录之前。临时目录占位只在边界处补上，宿主仍然走自己的路径策略。
