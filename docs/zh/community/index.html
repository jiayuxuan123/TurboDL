社区

没有聊天服务器，也没有 QQ 群。所有事情都在仓库里发生，可搜索、可追溯。

问题反馈

一份能复现的报告胜过十条意见。有用的报告会写清：TurboDL 版本（v0.2.0.8）、JDK 版本、目标链接或最小复现，以及你期望的结果。

提交 issue

讨论

本仓库没有开启 GitHub Discussions，所以本站也不假装有 —— 提问同样走 Issues。

参与贡献

修 bug、写新的插件后端、纠正文档都欢迎。请守住依赖方向（runtime → core），并在提 PR 前跑一遍 ./gradlew test —— 这套测试覆盖字节级正确性、续传与插件生命周期。

开源协议

MIT 协议，并附「插件生态」附加条款：插件是独立作品，可以自带任何协议；通过公开 API 交互不会让它变成 TurboDL 的衍生物。
