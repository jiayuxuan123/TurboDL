v0.3.1.0

2026-10-31

TurboDL 0.3.1.0 核心更新： 1. 自适应并发控制全面增强：新增 AdaptiveConcurrencyMode.DOWNWARD（默认），先以用户设定最高并发立即起跑拉满速度，在网络稳态后向下探求最小无损连接数；保留 UPWARD 模式供低并发上探场景使用。 2. 调度器性能与并发拉升重做：移除并发调度停滞，首段与后续分片立即喂饱多连接，杜绝小文件（如 30MB）连接数上不去的缺陷。 3. 完整性校验：支持 expectedSha256 流式哈希计算与校验，校验失败自动清理不可信侧车。 4. 宿主控制下放：开放慢启动错峰与初始并发策略，满足宿主应用与网盘场景多样化并发需求。 5. 包含 6 个核心模块完整 Maven 依赖包、全量 CLI 工具与 mavenLocal 离线压缩包（共 20 项产物）。
