Gradle

Publish the release's own POMs into your local Maven once, then depend on them by coordinate — the offline bundle below contains exactly those files:

shell
# 1) unpack the offline bundle into ~/.m2/repository
#    (or: unzip TurboDL-v0.3.1.0-mavenLocal.zip -d "$HOME/.m2/repository")
#
# 2) depend on it by coordinate / 按坐标依赖:
#    implementation("dev.turbodl:turbodl-core:0.3.1.0")
build.gradle.kts
dependencies {
    // required / 必需
    implementation("dev.turbodl:turbodl-core:0.3.1.0")

    // optional plugins / 可选插件
    implementation("dev.turbodl:turbo-plugin-runtime:0.3.1.0")
    implementation("dev.turbodl:turbo-plugin-bootstrap:0.3.1.0")
    implementation("dev.turbodl:turbo-plugin-hls:0.3.1.0")
    implementation("dev.turbodl:turbo-plugin-js:0.3.1.0")
    implementation("dev.turbodl:turbo-plugin-parser:0.3.1.0")
}
These coordinates are not on Maven Central yet. The offline bundle on the release page is the supported way to consume them — it is exactly the set of files Gradle publishes into a local repository.

What the bundle installs to

~/.m2/repository/dev/turbodl/turbodl-core/0.3.1.0<version>/turbodl-core-<version>.jar + .pom
~/.m2/repository/dev/turbodl/turbo-plugin-*/0.3.1.0one directory per plugin artifact
build.gradle.ktsimplementation("dev.turbodl:turbodl-core:0.3.1.0")

The bundle is a plain repository tree: unzip it at ~/.m2/repository and Gradle resolves it offline.

Command line

The release ships a self-contained CLI JAR. It needs only Java 17+ — no Gradle, no sources:

shell
java -jar turbodl-cli-all.jar <url> -o out.bin -c 64
java -jar turbodl-cli-all.jar <url> --json        # NDJSON, script/agent friendly
java -jar turbodl-cli-all.jar --batch tasks.txt   # one URL per line / 每行一个 URL

Exit codes: 0 success · 1 download failed · 2 usage error.

The flags worth knowing

-c, --connections1..256 · default 16
-l, --limitbytes per second, 0 = unlimited
-r, --retry0..50 per segment
-b, --batchone URL per line
--jsonNDJSON: start / timing / progress / completed / summary
--doh, --proxyDNS over HTTPS, or Direct / System / Manual / PAC
--no-tail-assist, --no-overlapturn the two endgame switches off

Every flag maps onto a field of TurboConfig — the CLI is a thin skin over the SDK.
