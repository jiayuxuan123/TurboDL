Why these are written plainly

Because the alternative is a document nobody reads. These pages say what the code does, including the parts that are inconvenient: no warranty, no signing pipeline, no isolation promises beyond what the category list enforces. If something here stops matching the code, that is a bug worth reporting — not a nuance to live with.
