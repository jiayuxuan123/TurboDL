Plugins/HLS VOD Backend

HLS VOD Backend

Treats an `.m3u8` URL as a stream to assemble rather than a text file to save: playlist resolution, variant selection, concurrent segments with per-segment retry, AES-128 decryption, byte ranges.

Explicitly refused

  • Live playlists (no `EXT-X-ENDLIST`)
  • DRM / `SAMPLE-AES`
  • fMP4 `EXT-X-MAP`
  • Discontinuities
Refused explicitly: an unsupported stream fails loudly instead of producing a file that looks fine and is not.
