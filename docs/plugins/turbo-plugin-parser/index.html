Platform Link Parser

Turns a share link into download requests: Weibo (best available MP4 + image sets), Xiaohongshu (watermark-free video + original images), Pixiv (every page's `urls.original`). Registers one `LinkParser` plus one `ProtocolClaim` per platform — the engine knows nothing about these three sites.

Explicitly refused

  • Logging in — a platform that needs a session returns null and the host's own account handling takes over
  • Pixiv animations (ugoira): a zip plus a frame-timing table needs image processing
  • Pixiv novels
  • Signed APIs (Douyin, Kuaishou, Bilibili): per-platform signature algorithms stay in the host
Its result type carries no path: a `DownloadRequest` needs a `destination: File`, but a parser runs before the host has chosen a directory. The temp-dir destination is filled in only at the boundary, so the host still applies its own path policy.
